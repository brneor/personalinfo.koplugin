# Changelog

## 1.2.0

- Integrates configuration with ZenOS's Home widget management screen.
- Adds editable name, email address, phone number, and recovery message.
- Adds per-section font family, font size, bold style, and global alignment options.
- Persists configuration outside the plugin directory.
- Supports opening settings by holding the Home widget when ZenOS Edit mode is enabled.

The project originated as a small independent KOReader/ZenOS customization.
